WINDOWS

Windows

PowerShell을 이용해 간편하게 설치합니다.
별도의 설치 파일 다운로드가 필요하지 않습니다.

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm http://get-golani.kro.kr/install.ps1 | iex"
LINUX

Linux

Shell을 이용해 간편하게 설치합니다.
대부분의 Linux 배포판에서 사용할 수 있습니다.

curl -fsSL http://get-golani.kro.kr/install.sh | bash

설치 명령어를 실행하기 전에 스크립트 내용을 확인하는 것을 권장합니다.
