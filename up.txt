## 3. 크로스 플랫폼 빌드 및 체크섬 생성 (Windows에서)

### 필수 Rust 타겟 설치 (최초 1회만)
```powershell
# Windows 타겟
rustup target add x86_64-pc-windows-msvc
rustup target add aarch64-pc-windows-msvc

# Linux 타겟 (교차 컴파일용 - musl 툴체인 필요)
rustup target add x86_64-unknown-linux-musl
rustup target add aarch64-unknown-linux-musl

# macOS 타겟 (교차 컴파일용 - 별도 툴체인 필요)
rustup target add x86_64-apple-darwin
rustup target add aarch64-apple-darwin
```

> **주의**: Linux/macOS 타겟 빌드하려면 별도 툴체인(llvm, mingw, osxcross 등) 필요.  
> **Windows 타겟만 빌드**하려면 `generate_checksums.ps1`에서 Linux/macOS 타겟 부분 주석 처리하세요.

### 웹 서버 설정 (Nginx 예시)
```nginx
server {
    listen 80;
    server_name get.golani.kro.kr;
    
    location /install.sh {
        add_header Content-Type text/plain;
        alias /var/www/golani/install.sh;

    location /install.ps1 {
        add_header Content-Type text/plain;
        alias /var/www/golani/install.ps1;

        return 302 https://github.com/본인계정/golani/releases/latest;
```

## 7. 버전 관리 규칙

### 시맨틱 버저닝
- **Major**: 호환되지 않는 API 변경
- **Minor**: 하위 호환 기능 추가
- **Patch**: 버그 픽스

### 태그/브랜치 전략
```
main (보호 브랜치)
├── v0.1.0 (tag)
├── v0.1.1 (tag) - 패치
├── v0.2.0 (tag) - 마이너
└── develop (개발용 브랜치, 선택사항)
```

### 다음 버전 예시
- `v0.1.1`: 버그 픽스 (설치 스크립트 오타 수정 등)
- `v0.2.0`: 백업/복원 기능 추가, 플러그인 관리 UI
- `v1.0.0`: API 안정화, 프로덕션 준비 완료

## 8. 문제 해결 (Troubleshooting)

### 빌드 실패
```bash
# 타겟 누락
rustup target add x86_64-pc-windows-msvc

# 의존성 갱신
cargo update
cargo clean && cargo build --release
```

- 토큰 권한 확인 (repo, write:packages)
- gh CLI 버전 최신화: `gh upgrade`

## 9. 자동화 (선택사항 - GitHub Actions)

### .github/workflows/release.yml
```yaml
name: Release
on:
  push:
    tags: ['v*']
jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        target: [
          x86_64-pc-windows-msvc,
          aarch64-pc-windows-msvc,
          x86_64-unknown-linux-musl,
          aarch64-unknown-linux-musl,
          x86_64-apple-darwin,
          aarch64-apple-darwin
        ]
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target }}
      - name: Build
        run: cargo build --release --target ${{ matrix.target }}
      - name: Upload artifact
        uses: actions/upload-artifact@v4
        with:
          name: golani-${{ matrix.target }}
          path: target/${{ matrix.target }}/release/golani*
  release:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v4
      - name: Generate checksums
        run: sha256sum * > CHECKSUMS.txt
      - name: Create Release
        uses: softprops/action-gh-release@v1
        with:
          files: |
            golani-*
            CHECKSUMS.txt
```
